# Chapter Time — read &amp; watch

A calm reading-and-video companion for the naklios.dev family, keyed to the **abhyas** knowledge graph. Class 1–5. Runs standalone, or as a hosted app inside naklios (sibling of [Abhyas](../abhyas-app), the practice app).

For each chapter (a concept in the graph) it shows:

- **About** — what the chapter is about, what it *builds on*, and what it *opens up* next (straight from the knowledge graph).
- **Watch** — a curated video lesson when one exists, otherwise a one-tap "find a video on YouTube" (opens in a new tab; nothing is embedded or tracked until you choose to watch).
- **Now practise it** — a jump to the same concept in Abhyas.
- **Mark as read** — per-viewer progress, stored on the device.

## Subject-agnostic by design

Branding and banding come from the data's `meta` (`subject`, `grades`), not from hard-coded strings. Point it at a different subject's spine from the abhyas engine (Physics, Chemistry, …) and the same app becomes that subject's Chapter Time. Curated videos live in `data/videos.json` keyed by concept id, so they survive a data rebuild.

## How it's built

- **Single-file app** — [`index.html`](index.html), zero build step, deployable static.
- **Data** — [`data/chapters-k5.js`](data/chapters-k5.js): a snapshot of the abhyas concept spine (`window.CHAPTER_DATA`), regenerated by [`tools/build-data.py`](tools/build-data.py). Do **not** edit the abhyas engine from here.
- **naklios guest** — vendors [`sdk/naklios.js`](sdk/naklios.js): lifecycle, title, and a storage adapter (`naklios.fs` progress.json ↔ localStorage). It keeps its own calm warm-paper palette (plum accent) and does not adopt the host theme.
- **Sovereign** — no account, no backend, no telemetry. What you've explored stays on the device.

## Run it

```bash
python3 -m http.server 4181 --directory .
```

Then visit `http://127.0.0.1:4181`.
